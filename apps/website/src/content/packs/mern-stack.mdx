## What's in the pack

The MERN stack is the original JavaScript-everywhere web stack: a document database (MongoDB), a thin HTTP framework on Node (Express), a SPA frontend (React), and a runtime that ties them together (Node.js). The four icons in this pack are the ones almost every MERN tutorial, boilerplate repo, and job listing puts side-by-side — bundled here so you don't have to hunt them down one at a time.

## How to use them

For a classic client/server diagram, line them up horizontally in database → API → frontend order: **MongoDB → Express → Node.js → React**. The Express and Node logos share a similar vibe (green, monochrome), so give them vertical breathing room if they sit next to each other. If you're illustrating a full-stack request, an arrow curving from React back to MongoDB through Express makes the round-trip obvious.
