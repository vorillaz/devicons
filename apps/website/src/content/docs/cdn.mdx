Every Devicons package is on npm, so every file is reachable through public CDNs. Use this for prototypes, CodePen demos, zero-build stacks, or loading SVGs from static HTML.

## Icon font

One `<link>` tag is enough.

<CdnTabs
  client:load
  pkg={FONT_PKG_NAME}
  version={FONT_PKG_VERSION}
  path="dist/devicons.css"
  template={`<link
  rel="stylesheet"
  href="{url}"
/>`}
/>

Then use it:

```html
<i class="devicon devicon-react"></i>
```

See the [icon font guide](/docs/icon-font) for sizing and color.

## SVG sprite

A single `<svg>` containing every icon as a `<symbol>`. Reference with `<use>`. Good for pages with many icons.

<CdnTabs
  client:load
  pkg={CORE_PKG_NAME}
  version={CORE_PKG_VERSION}
  path="export-files/sprite.svg"
  fragment="#react"
  template={`<svg class="icon" width="24" height="24" aria-label="React logo">
  <use href="{url}"></use>
</svg>`}
/>

<Note variant="info" title="Symbol IDs match icon slugs">

`<symbol>` IDs are the slugs from the [icon library](/icons): `#react`, `#vue`, `#nextjs-icon`, etc.

</Note>

## Raw SVGs

Every icon is available as an individual SVG under `export-files/icons/`.

### As `<img>`

```html
<img
  src="https://cdn.jsdelivr.net/npm/@dev.icons/core@latest/export-files/icons/react.svg"
  alt="React logo"
  width="48"
  height="48"
/>
```

### Fetch and inject

Fetching raw SVG markup lets you style it with CSS.

```html
<span class="icon" data-icon="postgresql" aria-hidden="true"></span>

<script type="module">
  const BASE =
    "https://cdn.jsdelivr.net/npm/@dev.icons/core@latest/export-files/icons";

  for (const el of document.querySelectorAll("[data-icon]")) {
    const slug = el.getAttribute("data-icon");
    const res = await fetch(`${BASE}/${slug}.svg`);
    el.innerHTML = await res.text();
  }
</script>
```

### ES module via Skypack

No install, no bundler:

```html
<script type="module">
  import { react, vue, postgresql } from "https://cdn.skypack.dev/@dev.icons/core@latest";

  document.getElementById("logo").innerHTML = react;
</script>
```

### Icon variants

Most brands have a full logo and a glyph-only mark:

| Path | Example |
| --- | --- |
| `icons/<slug>.svg` | `icons/react.svg` |
| `icons/<slug>-icon.svg` | `icons/nextjs-icon.svg` |

## Versioning and caching

All CDNs honor semver ranges:

```
https://<cdn>/@dev.icons/core@1.2.3/export-files/icons/react.svg
```

<Note variant="tip" title="Cache behavior">

- **Pinned** (`@1.2.3`) -- cached forever at the edge. Use in production.
- **Range** (`@^1`) -- revalidated periodically, picks up patches and minors.
- **`@latest`** -- changes with every release. Fine for demos only.

</Note>

## When CDN is not enough

- Tree-shaken, typed components: [`@dev.icons/react`](/docs/react), [`@dev.icons/vue`](/docs/vue), [`@dev.icons/svelte`](/docs/svelte)
- Programmatic metadata: install [`@dev.icons/core`](/docs/core) locally
- SSR markup without a runtime: [`@dev.icons/core`](/docs/core) exports each icon as a plain SVG string
