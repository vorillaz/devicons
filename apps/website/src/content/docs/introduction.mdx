Devicons started as a web font. Now it ships as native packages for React, Vue, and Svelte too.

## Why Devicons

- Icons for brands, languages, frameworks, cloud services, and tooling
- Full-color and monochrome variants for every icon
- Raw SVG, icon font, sprites, and framework components
- Tree-shakeable imports, no runtime fetches
- MIT licensed

## Design

Every icon follows the same grid, optical weight, and corner radius. Any two icons look like they belong together.
