## About the Google AI Studio logo

The current Google AI Studio icon is two slanted, rounded bars stacked into an "S"-like shape. Soft gradients run across them in Google's colors: green (#00B95C) into blue (#3186FF) on the upper bar, and blue into yellow and red (#FC413D) on the lower bar.

The icon reads well on light and dark backgrounds. The lockup pairs it with a "Google AI Studio" wordmark in dark grey (#212226), which fades on dark surfaces, so use the monochrome lockup there.

## When to use this logo

Use Google AI Studio in LLM provider pickers, Gemini API quickstarts and SDK setup guides, and prompt-engineering tutorials. It also fits AI developer tool comparisons and architecture diagrams that show where API keys come from. Use the standalone icon for favicons, avatars and small UI slots. It pairs naturally with Google Gemini, Google Vertex AI, Gemma, the OpenAI Platform and Anthropic Console.
