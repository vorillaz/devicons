## About the Penpot logo

The Penpot logo is a black line drawing of a cube-shaped pencil box with the tips of several pencils sticking out of the top. It is a single-colour outline mark, so it sits comfortably next to UI screenshots and wireframes.

The black outline disappears on dark surfaces, so use the monochrome version there.

## When to use this logo

Use Penpot in design tool comparisons, open-source design system docs, self-hosting guides and handoff workflow diagrams. It pairs naturally with Figma, Sketch, Adobe Illustrator, Storybook and Docker.
