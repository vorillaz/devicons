## About the Bitwarden logo

The Bitwarden icon is a shield in Bitwarden Blue (#175DDC) with a solid left half and an open right half, so the background shows through. The lockup sets "bitwarden" in the same blue next to the shield, with "bit" in bold and "warden" in a lighter weight. Both come from Bitwarden's official logo kit.

The blue reads well on light backgrounds and stays visible on dark ones, though the thin wordmark is easier to read in monochrome white there.

## When to use this logo

Use Bitwarden in password manager comparisons, security and SSO setup guides, self-hosting stacks and docs for the Bitwarden CLI or Secrets Manager SDKs. It pairs naturally with Okta, Auth0, Vault, Proton Mail and Docker.
