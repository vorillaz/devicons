## About the Aya logo

The Aya mark is a sprig of four rounded leaves growing from a single point, with the largest leaf at the bottom. The full logo sets the mark next to a clean sans-serif "Aya" wordmark. In its current artwork on cohere.com, Cohere Labs shows the leaves in lime (#CEFF00) and the wordmark in white on dark backgrounds, and the color files here follow that. Some icon sets still show the leaves in an older blue (#416FDC).

The lime leaves and white wordmark are hard to see on white, so place the color logo on a dark surface. Use the monochrome version on light pages.

## When to use this logo

Use the Aya logo in multilingual model comparisons, open-weight model catalogs, LLM pickers and benchmark charts that cover languages beyond English. It also fits translation and localization pipelines that run Aya models. Pair it with the Cohere logo for the parent company. Hugging Face, Qwen, Meta Llama and Mistral AI are natural neighbors.
