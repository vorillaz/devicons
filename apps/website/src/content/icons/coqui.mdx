## About the Coqui logo

The Coqui mark is a smiling frog face drawn in a single outline weight, with round goggle-like eyes and two small dots for nostrils. The full logo pairs the frog with a rounded lowercase "coqui" wordmark. The frog is sea green (#5EAE91) and the wordmark is a dark teal (#03363D), the same colors used in the logo in the Coqui TTS README.

Coqui is no longer active. By January 2024 the coqui.ai homepage read "Coqui is shutting down", and the coqui-ai/TTS repository is now archived. The dark teal wordmark is hard to read on dark backgrounds, so use the monochrome version there.

## When to use this logo

Use the Coqui logo in text-to-speech model comparisons, voice cloning tool lists, and docs or tutorials that still run Coqui TTS or the open XTTS-v2 weights. It also suits historical overviews of open-source speech synthesis. Natural pairings are Hugging Face, ElevenLabs, Fish Audio and PyTorch.
