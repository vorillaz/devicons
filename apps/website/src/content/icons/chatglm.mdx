## About the ChatGLM logo

The current ChatGLM mark is two tilted blue rings, one stacked behind the other: a deep blue (#1041F3) front ring and a lighter blue (#3762FF) back ring. The lockup on chatglm.cn pairs it with the Chinese name 智谱清言 (Zhipu Qingyan) above a smaller "ChatGLM.cn" line, in dark gray. Older ChatGLM icons in some icon sets show a different, elephant-style mark.

The blue rings work on light and dark backgrounds. The dark gray text does not, so use the monochrome lockup in dark themes.

## When to use this logo

Use the ChatGLM logo for the consumer chat app and the ChatGLM model line: chatbot comparisons, LLM model pickers, and docs that run open ChatGLM or GLM models. For the company or its developer platform, use the Z.ai logo instead. It pairs naturally with Z.ai, Kimi, Qwen, DeepSeek, MiniMax and Doubao.
