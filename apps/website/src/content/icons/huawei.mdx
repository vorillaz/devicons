## About the Huawei logo

The Huawei mark is a fan of eight petal-shaped segments that open upward from a single point, like a stylized flower. The full logo is the stacked version, with the "HUAWEI" wordmark set in capitals below the flower. Both files come from the vector logo on huawei.com.

The petals use a radial red gradient that runs from a pale peach highlight (#F1BCA2) through red (#D71718) to deep crimson (#971E23). The wordmark is near-black (#040000). The flower stays visible on dark backgrounds but the wordmark does not, so use the monochrome version in dark themes.

## When to use this logo

Use the Huawei logo for device compatibility lists, telecom and 5G network diagrams, HarmonyOS or HMS Core integration docs, and vendor comparison pages for networking or enterprise hardware. For the cloud platform, use the Huawei Cloud logo. It pairs naturally with Ericsson, Nokia, ZTE, Xiaomi and Samsung.
