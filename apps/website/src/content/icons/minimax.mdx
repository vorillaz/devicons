## About the MiniMax logo

The MiniMax mark is a single rounded line that rises and falls in tall loops, like a sound wave or heartbeat trace. It runs as a horizontal gradient from magenta (#E2167F) to orange (#FF623A). The horizontal lockup sets it beside a bold, uppercase "MINIMAX" wordmark in black. The files here are converted from the official vector logo assets in the MiniMax Brand Book.

The gradient mark works on both light and dark backgrounds. The black wordmark does not, so use the monochrome lockup in dark themes.

## When to use this logo

Use the MiniMax logo in LLM provider pickers, model comparison tables, API gateway docs and AI stack diagrams that include MiniMax M-series text models or H-series video models. It also fits speech and music generation tool lists. It pairs naturally with Hailuo AI, Kimi, Moonshot AI, Zhipu (Z.ai), DeepSeek and Qwen.
