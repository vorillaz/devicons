## About the MetaGPT logo

The MetaGPT mark is an interlaced knot of four rounded loops arranged like a four-leaf clover, with a curved ribbon running diagonally through the center. The full logo pairs the mark with a geometric "MetaGPT" wordmark. The mark comes from the vector logo on the official MetaGPT documentation site (docs.deepwisdom.ai), and it matches the logo in the GitHub README.

The logo is black, with a white version used on dark pages. Use the monochrome version, which follows the text color, on dark backgrounds.

## When to use this logo

Use the MetaGPT logo in multi-agent framework comparisons, LLM agent architecture diagrams, research and tutorial pages about role-based agents, and Python AI tooling lists. It pairs naturally with LangChain, LangGraph, AutoGen, CrewAI and OpenAI, and with the LLM providers you configure MetaGPT to use.
