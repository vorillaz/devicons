## About the Alibaba logo

The Alibaba mark is a single orange calligraphic stroke that loops into a stylized lowercase "a", with a small smile tucked inside the curve. In the full logo, a heavy geometric "Alibaba" wordmark in the same orange sits to the right of the mark. These files are taken from the current logo on alibabagroup.com.

The mark and the wordmark use one flat color, Alibaba orange (#FF5A00). Orange reads well on both white and near-black backgrounds, so the colored versions work in light and dark themes. Use the monochrome version when you need a single-ink logo.

## When to use this logo

Use the Alibaba logo for the parent company itself: e-commerce integration guides, marketplace and payment provider lists, investor or market comparison pages, and diagrams that show Alibaba's group of businesses. For the cloud platform use the Alibaba Cloud logo, and for the language models use Qwen. It sits naturally next to Alibaba Cloud, Qwen, Tencent and JD.com.
