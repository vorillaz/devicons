## About the AUTOMATIC1111 logo

The AUTOMATIC1111 Stable Diffusion web UI does not publish an official logo. Its repository and interface have no brand assets. This icon is the community mark used in the Lobe Icons set: a bold geometric "A" followed by four diagonal stripes that fade out to the right, like a motion trail.

The mark uses a single magenta-red, #E00054, and gets the fade from opacity steps. The color version works on both light and dark backgrounds. The monochrome version keeps the "A" and its first stripe, because the overlapping faded stripes would merge into one solid shape at a single opacity.

## When to use this logo

Use it for the AUTOMATIC1111 web UI in local Stable Diffusion setup guides, extension and model compatibility tables, and image generation tool comparisons. It also works in GPU requirement notes, self-hosting docs and Colab or RunPod templates. It pairs naturally with Stability AI, ComfyUI, Hugging Face, Civitai and other Stable Diffusion front ends.
