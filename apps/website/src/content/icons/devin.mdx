## About the Devin logo

The Devin symbol is built from three rounded hexagons joined into a single, propeller-like shape. The full logo sets the symbol next to a clean sans-serif "Devin" wordmark. Both files come from the official brand assets page on devin.ai, which also hosts the Cognition logos.

The official logo is black on light backgrounds, with a white version for dark ones. Use the monochrome version, which follows the text color, in dark themes.

## When to use this logo

Use the Devin logo in AI coding agent comparisons, engineering tool stacks, integration pages for Slack, GitHub or Linear workflows, and docs that explain how to hand tickets to an autonomous agent. It pairs naturally with Claude Code, Codex, GitHub Copilot, Cursor and Windsurf.
