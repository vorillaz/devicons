## About the Trustpilot logo

The Trustpilot icon is a five-pointed star in bright green (#04DA8D) with a small dark green (#126849) notch in its lower right arm. The lockup adds "Trustpilot" in a clean sans serif. Both use the star colours from Trustpilot's current brand, and the wordmark is set in black for light backgrounds.

The green star reads well on light and dark backgrounds. The black wordmark disappears on dark surfaces, so use the icon or the monochrome lockup there.

## When to use this logo

Use Trustpilot in customer review integrations, e-commerce trust badges, marketing stack diagrams and docs for TrustBox widgets or the Trustpilot API. It pairs naturally with Shopify, WooCommerce, Google, Stripe and Zendesk.
