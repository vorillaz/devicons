## About the Microsoft Office logo

This is the Microsoft Office logo from Microsoft's 2019 icon refresh. It is a folded, rounded "O", like an open door, in red and orange gradients that run from dark red (#A4070A) to bright red (#F32B44). Microsoft has since moved the suite to the Microsoft 365 name, but this logo is still the recognised mark for Office.

The logo reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft Office in office suite comparisons, document workflow diagrams and legacy docs that still say Office or Office 365. For individual apps, pair it with Microsoft Word, Microsoft Excel, Microsoft PowerPoint and Microsoft Outlook, or compare it with Google Workspace.
