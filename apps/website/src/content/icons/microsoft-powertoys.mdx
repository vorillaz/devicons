## About the Microsoft PowerToys logo

The PowerToys icon looks like a retro control panel. A beige frame (#D7CCB3 to #F2E6CA) surrounds a grey screen (#666) showing four vertical colour bars in orange-red (#D83B01), yellow (#FFB900), green (#56B60E) and blue (#0078D4), the colours of the Microsoft logo. Three beige buttons sit below the screen.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft PowerToys in Windows productivity setups, developer workstation guides and dotfiles or setup script READMEs. It pairs naturally with Windows Terminal, PowerShell, Visual Studio Code and Microsoft Windows.
