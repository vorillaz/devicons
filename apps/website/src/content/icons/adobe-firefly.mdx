## About the Adobe Firefly logo

The Firefly icon is a red rounded square (#EB1000) with the white letters "Fi" and a small four-pointed sparkle above the "i". It follows the Adobe app icon system, where each product gets a two-letter mnemonic on a colored tile. This is the icon that firefly.adobe.com uses. The lockup pairs it with an "Adobe Firefly" wordmark in black.

The red tile reads well on both light and dark backgrounds. The black wordmark disappears on dark surfaces, so use the monochrome lockup there.

## When to use this logo

Use Adobe Firefly in AI image and video generator comparisons, creative workflow diagrams, and docs for Creative Cloud or Firefly API integrations. It also fits model pickers in creative apps and slides about generative fill or AI video in production work. Use the standalone icon in app grids and small UI slots. It pairs naturally with Adobe, Photoshop, Midjourney, DALL-E, Runway and Google Veo.
