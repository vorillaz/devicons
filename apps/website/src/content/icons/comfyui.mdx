## About the ComfyUI logo

The Comfy logomark is a chunky, slanted "C" drawn with rounded blocks, with a short tab that sticks out from its lower left like a node connector. The core logo spells "Comfy" in the same blocky, slanted letterforms, with the logomark as its first letter. Comfy's brand portal lists Comfy Yellow #F2FF59 as the main color and Comfy Ink #211927 as its dark partner.

Comfy Yellow is bright and works on dark backgrounds, but it almost disappears on white. On light backgrounds, use the monochrome version. The brand portal asks that the logos not be distorted, recolored or outlined.

## When to use this logo

Use ComfyUI in diffusion workflow tutorials, node-graph and pipeline diagrams, image and video generation tool comparisons, and docs for custom nodes or the ComfyUI API. It also fits self-hosted GPU setup guides and Comfy Cloud deployment notes. It pairs naturally with Stability AI, AUTOMATIC1111, Hugging Face, Black Forest Labs Flux and other open image models.
