## About the Alibaba Cloud logo

The Alibaba Cloud mark is two rounded bracket shapes facing each other, with a short horizontal bar between them. In the full logo, a condensed "Alibaba Cloud" wordmark follows the mark. Both files come from the vector logo in the alibabacloud.com site header.

The whole logo uses one flat orange, #FF6A00. It holds strong contrast on white and on dark backgrounds, so the colored versions work in either theme. The monochrome version keeps the bracket-and-bar mark as a single-ink silhouette.

## When to use this logo

Use the Alibaba Cloud logo in multi-cloud architecture diagrams, deployment target selectors, infrastructure-as-code provider docs, region and pricing comparisons, and pages about Model Studio or Qwen API hosting. It pairs naturally with AWS, Google Cloud, Microsoft Azure, Huawei Cloud and Tencent Cloud, and with the Qwen logo for AI workloads.
