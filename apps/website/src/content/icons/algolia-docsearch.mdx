## About the DocSearch logo

The DocSearch symbol is an outlined capital "D" filled with horizontal lines of different lengths, like lines of text on a page. The full logo pairs the symbol with an uppercase "DOCSEARCH" wordmark. The symbol comes from the favicon and header of docsearch.algolia.com. The full logo comes from the DocSearch logo file in the project's official GitHub repository.

The symbol is blue-violet (#5468FF). In the full logo, the inner lines and the wordmark are black, so they disappear on dark backgrounds. Use the monochrome version, or the all-blue symbol, in dark themes.

## When to use this logo

Use the DocSearch logo in documentation tooling comparisons, "search by" credits in docs footers, static site generator plugin lists, and setup guides for Docusaurus, VitePress or other docs frameworks. It pairs naturally with Algolia, Docusaurus, VitePress, Starlight, Mintlify, Typesense and Meilisearch.
