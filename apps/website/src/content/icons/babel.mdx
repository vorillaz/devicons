## About the Babel logo

The Babel logo is the word "BABEL" in yellow (#F9DC3E) hand-brushed capitals, with rough edges and drips like paint strokes. The project launched in 2014 as 6to5 and was renamed Babel in 2015.

The yellow letters have little contrast on white, so place the logo on a dark background or use the monochrome version on light ones.

## When to use this logo

Use Babel in JavaScript build pipeline diagrams, transpiler and bundler comparisons, browser support docs and babel.config.js or .babelrc file icons. It pairs naturally with webpack, TypeScript, React, SWC and ESLint.
