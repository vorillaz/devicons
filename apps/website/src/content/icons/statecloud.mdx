## About the State Cloud logo

The State Cloud mark is a cloud outline whose right side curls into a circular arrow pointing upward. The full logo stacks the Chinese name 天翼云 over the English "State Cloud" beside the mark, as shown in the header of ctyun.cn. The service is run by Tianyi Cloud Technology (天翼云科技有限公司), a China Telecom subsidiary, and is sold outside mainland China as eSurfing Cloud.

The whole logo is a single red (#DF0428), which stays legible on both light and dark backgrounds.

## When to use this logo

Use the State Cloud logo in cloud provider comparisons for the Chinese market, deployment and region pickers, compliance or government cloud architecture diagrams, and model API lists that include its Xirang (息壤) AI compute platform. It pairs naturally with Alibaba Cloud, Huawei Cloud, Tencent Cloud, Baidu AI Cloud and Volcano Engine.
