## About the OpenRouter logo

The OpenRouter glyph is a single rounded shape: a ring for the "O" whose body runs into a diagonal tail on the right, so it reads as "OR". The official brand page lists four colorways: Grape (#7624F4) and Ink (#03080A) for light backgrounds, and Volt (#C8FF00) and Cloud for dark ones. The primary horizontal lockup pairs the Grape glyph with a lowercase "openrouter" wordmark in Ink.

The Grape glyph works on both light and dark backgrounds. The Ink wordmark does not work on dark backgrounds, so use the monochrome version there. OpenRouter asks that the marks not be stretched, recolored or remixed.

## When to use this logo

Use OpenRouter in LLM provider pickers, model routing and gateway architecture diagrams, and docs for SDKs or coding tools that accept an OpenRouter API key. It also fits pricing and latency comparison tables. It pairs naturally with OpenAI, Anthropic, Google Gemini, Meta Llama and other model providers, and with LiteLLM or Vercel AI SDK in a gateway stack.
