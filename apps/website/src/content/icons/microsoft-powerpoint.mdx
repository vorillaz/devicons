## About the Microsoft PowerPoint logo

The PowerPoint icon is a round, layered shape in warm gradients, from red (#D12B18) and orange (#FF3C00, #FFA05C) to pink (#FF66FB). A dark red tile in front carries a white "P". It uses the same layered Fluent layout as Microsoft's other Microsoft 365 app icons.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft PowerPoint for .pptx file-type icons, export-to-slides buttons, presentation tool comparisons and Office Add-in docs. It pairs naturally with Google Slides, Keynote, Canva, Microsoft Word and Microsoft Excel.
