## About the Luma logo

The Luma symbol is two flat planes that meet at a fold: a tall parallelogram, and below it a diamond. Both are set at 65% opacity, so the area where they overlap reads darker, like a folded sheet. The full logo puts the symbol next to a bold "Luma" wordmark set in Graphik. Both files come from the official SVGs in Luma's media kit, and they match the logo on lumalabs.ai.

Luma's 2026 brand guidelines allow the logo only in black or white, with no gradients and no changes to the symbol's opacity. The color files are the black versions, so use the monochrome version on dark backgrounds. In the monochrome version, thin gaps between the three faces stand in for the opacity layering.

## When to use this logo

Use the Luma logo in AI video model comparisons, generative media stack diagrams, model pickers for apps that call the Luma API, and docs or tutorials about Ray video generation, Uni images or Luma Agents. It pairs naturally with Runway, Pika, Kling, Google Veo and OpenAI Sora in video generation lineups.
