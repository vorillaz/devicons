## About the Google Vertex AI logo

The Vertex AI icon comes from Google Cloud's official product icon set. It shows columns of rounded bars and dots that collect into a downward-pointing chevron, drawn in Google's four colors: red (#EA4335), yellow (#FBBC04), green (#34A853) and blue (#4285F4). The lockup pairs it with a "Vertex AI" wordmark in dark grey (#212226), the color of the "Google Cloud" text in the current Google Cloud logo.

The icon reads well on light and dark backgrounds. The wordmark does not, so use the monochrome lockup on dark surfaces. At Google Cloud Next '26 in April 2026, Google renamed Vertex AI to Gemini Enterprise Agent Platform; Vertex AI Studio became Agent Studio and Vertex AI Agent Engine became Agent Runtime. The Vertex AI mark still appears across existing docs, SDKs and architecture diagrams.

## When to use this logo

Use Vertex AI in cloud AI platform comparisons, MLOps and model-serving architecture diagrams, and LLM provider pickers that list Google's enterprise endpoint. It also fits docs for SDK integrations that call Gemini through Google Cloud. It pairs naturally with Google Cloud, Gemini and BigQuery, and with AWS Bedrock and Azure AI on the other clouds.
