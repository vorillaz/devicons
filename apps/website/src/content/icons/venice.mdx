## About the Venice logo

The Venice symbol, which the brand calls "the keys", shows two crossed keys with clover-shaped bows beneath a small chevron crest. The primary logo is a vertical lockup: a flowing script "Venice" wordmark with the keys centered below it. Both files come from the official Venice brand kit. Venice was founded by Erik Voorhees in 2024.

The logo is Deep Blue (#0E2942) on light backgrounds and Off White (#F7F5ED) on dark ones. Some icon sets still show the keys in orange-red, but the current kit approves only Deep Blue, Off White, white or black. On dark backgrounds, use the monochrome file.

## When to use this logo

Use the Venice logo in private or uncensored AI tool lists, LLM provider pickers, model routing tables, and docs for apps or agents built on the Venice API. It fits "Built in Venice" integration pages and privacy-focused AI stack diagrams. Natural pairings are OpenRouter, Poe, DeepSeek, Mistral and Grok.
