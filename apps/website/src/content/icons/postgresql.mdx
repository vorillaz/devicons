## About the PostgreSQL logo

The PostgreSQL mark is an elephant head — colloquially "Slonik" (Russian for "little elephant") — a nod to the elephant's long memory as a metaphor for a database that never forgets. The elephant idea traces back to a suggestion on the project's mailing lists in the late 1990s, and the elephant has been the project's identity across major releases ever since.

The brand blue (#336791) is the working default; on dark backgrounds a thin outline keeps the elephant silhouette readable below 32px. The [PostgreSQL Trademark Policy](https://www.postgresql.org/about/policies/trademarks/) permits editorial and non-endorsement use — fine for stack diagrams and architecture posts.

## When to use this logo

Use PostgreSQL in architecture diagrams, data-stack illustrations, migration guides ("moving from MySQL to Postgres"), and comparison pages with MongoDB or SQLite. For ORM content (Prisma, Drizzle, TypeORM) it's a common pairing — stack the elephant left of the ORM mark at equal visual weight.
