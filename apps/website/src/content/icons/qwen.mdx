## About the Qwen logo

The current Qwen mark is three rounded, parallelogram-like blue shapes arranged in a triangular pinwheel. The full logo pairs the mark with a geometric "Qwen" wordmark. Both files come from the vector logo used by Qwen Chat (chat.qwen.ai), and they match the logo on qwen.ai. An earlier version of the logo used a purple hexagram mark and an italic wordmark.

The mark is a vivid blue (#082DFF) and the wordmark is black. The black wordmark disappears on dark backgrounds, so use the monochrome version, or the mark on its own, in dark themes.

## When to use this logo

Use the Qwen logo in model comparison tables, LLM provider or model pickers, benchmark charts, open-weight model catalogs, and docs for inference servers or SDK integrations that run Qwen models. It pairs naturally with DeepSeek, Llama, Mistral, Kimi and GLM, and with Alibaba Cloud when you show where the models are hosted.
