## About the SillyTavern logo

The SillyTavern mark is a brain drawn in thick outlines, with circuit-board traces that end in round pads branching out on both sides. Bold white "ST" initials sit across the middle. The icon comes from the official vector logo in the SillyTavern repository, which matches the logo on sillytavern.app. The full logo pairs the mark with a plain "SillyTavern" wordmark.

The brain is a deep red (#A11B1B) and the initials are white (#FFFFFF), made for the dark interface the app uses. On white the initials disappear, so use the monochrome version on light backgrounds.

## When to use this logo

Use the SillyTavern logo in lists of LLM chat frontends, self-hosting guides, and docs for local inference backends that support it as a client. It also fits overviews of chat interfaces for local and cloud models, and setup guides that connect a frontend to an API key or a self-hosted server. Natural pairings are Ollama, LM Studio, KoboldCpp, Open WebUI and OpenRouter.
