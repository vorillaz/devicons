## About the 360 Zhinao logo

The 360 Zhinao mark is a blue ring cut by a sweeping wave that wraps a cluster of rounded, interlinked node shapes, giving it a molecular, network-like form. It is filled with a gradient that runs from light blue (#12B7FA) to a deeper blue (#006FFB), the same artwork used as the favicon on ai.360.com.

On ai.360.com the mark sits beside a thin "360智脑" wordmark in dark grey (#373838). The lockup here pairs the mark with the "360" numerals in that same grey. The gradient mark reads well on light and dark backgrounds, but the grey numerals get dim on dark surfaces, so use the mono version there.

## When to use this logo

Use the 360 Zhinao logo in model comparison tables of Chinese LLMs, provider pickers in multi-model chat apps, benchmark write-ups and docs for running the open 360Zhinao-7B checkpoints from Hugging Face or ModelScope. It sits naturally next to Qwen, DeepSeek, Baichuan, Zhipu GLM and Kimi. Prefer the standalone mark when space is tight.
