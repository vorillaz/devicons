## About the Cal.com logo

The Cal.com logo is a wordmark: "Cal.com" in a bold geometric sans serif, set in near-black (#292929). The project was called Calendso before it took the Cal.com name in 2021.

The dark wordmark disappears on dark surfaces, so use the monochrome version there.

## When to use this logo

Use Cal.com in scheduling tool comparisons, self-hosted SaaS stacks, booking flow diagrams and docs for the Cal.com API, embeds or Atoms. It pairs naturally with Calendly, Google Calendar, Zoom, Next.js and Prisma.
