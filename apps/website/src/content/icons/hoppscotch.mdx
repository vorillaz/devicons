## About the Hoppscotch logo

The Hoppscotch logo is a mint-green planet with a tilted ring and three round dots on its surface, shaded with gradients from bright mint (#00D196) to green (#00B381). The project launched in 2019 as Postwoman before taking the Hoppscotch name.

The green logo reads well on light and dark backgrounds.

## When to use this logo

Use Hoppscotch in API client comparisons, developer tool stacks, API docs with "try it" links and self-hosting guides. It pairs naturally with Postman, Insomnia, Bruno, Swagger and GraphQL.
