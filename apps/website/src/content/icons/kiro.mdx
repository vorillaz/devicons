## About the Kiro logo

The Kiro mark is a small white ghost with two black oval eyes, set on a rounded purple square. The full logo pairs the mark with an outlined, rounded "KIRO" wordmark in capital letters. The mark comes from the vector icon served on kiro.dev, and the wordmark matches the wordmark image used on kiro.dev.

The brand purple is #9046FF. On kiro.dev the wordmark is drawn in white on a dark page. This lockup uses a black wordmark for light backgrounds, so on dark backgrounds use the monochrome version or the mark on its own.

## When to use this logo

Use the Kiro logo in AI coding tool comparisons, IDE and editor pickers, developer surveys, and docs that explain spec-driven development or how to set up Kiro with your repositories. It pairs naturally with Cursor, Windsurf, VS Code, Claude Code and GitHub Copilot, and with AWS in diagrams that show where Kiro fits in an AWS stack.
