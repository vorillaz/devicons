## About the Microsoft SharePoint logo

The SharePoint icon is three overlapping circles in teal gradients, from bright aqua (#78EDFF) to deep teal (#003B5D). A dark teal tile in front carries a white "S". The circles suggest people and sites linked together.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft SharePoint in intranet and document management comparisons, Microsoft 365 architecture diagrams and docs for the SharePoint REST API, SharePoint Framework (SPFx) or Microsoft Graph. It pairs naturally with Microsoft Teams, Microsoft OneDrive, Confluence and Microsoft Outlook.
