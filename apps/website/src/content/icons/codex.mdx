## About the Codex logo

The Codex mark is a rounded, cloud-like shape holding a terminal prompt: a chevron and an underscore, the ">_" you see at a command line. That fits a product that first shipped in April 2025 as the Codex CLI. In color, the shape is filled with a vertical gradient that runs from lavender (#B1A7FF) through mid blue (#7A9DFF) to deep blue (#3941FF).

The gradient symbol works on both light and dark backgrounds. The lockup puts it next to a black "Codex" wordmark, so on dark surfaces use the monochrome version with currentColor or a light fill.

## When to use this logo

Use Codex in AI coding assistant comparisons, agent tooling matrices and docs that cover the Codex CLI or IDE extensions. It also fits CI and code-review workflow diagrams where an agent opens pull requests. It pairs naturally with OpenAI, GitHub Copilot, Cursor and Claude Code, and with the terminal and editor icons in a developer-tools stack.
