## About the Baidu AI Cloud logo

The Baidu AI Cloud mark is a hexagonal cube drawn as three separate faces with gaps between them. The full logo pairs the cube with the Chinese wordmark 百度智能云, as shown in the header of cloud.baidu.com.

Each face has its own gradient: the top runs green (#0DF178 to #25D979), the left blue to violet (#0D5EFF to #9C62FF), and the right pink-red to orange (#FF336B to #FF9C4B). The wordmark is near-black (#282828). The site draws the gradients as an embedded bitmap, so these files rebuild them as vector gradients sampled from it. The dark wordmark disappears on dark backgrounds, so in dark themes use the mark alone or the monochrome version.

## When to use this logo

Use the Baidu AI Cloud logo in cloud provider comparisons, LLM provider pickers and model gateways that call ERNIE or other models through Qianfan, and in deployment diagrams for workloads hosted on Baidu's cloud. It pairs naturally with Baidu and ERNIE, and with Alibaba Cloud, Tencent Cloud, Huawei Cloud and Volcano Engine in overviews of Chinese cloud platforms.
