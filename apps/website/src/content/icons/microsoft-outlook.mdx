## About the Microsoft Outlook logo

The Outlook icon is an open envelope built from layered blue panels, from sky blue (#3BD5FF) to deep blue (#165AD9), with lavender highlights (#C4B0FF). A blue tile in front carries a white "O". It uses the same layered Fluent layout as Microsoft's other Microsoft 365 app icons.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft Outlook in email client comparisons, calendar and scheduling integrations, "add to Outlook" buttons and docs for the Microsoft Graph mail and calendar APIs. It pairs naturally with Gmail, Microsoft Teams, Google Calendar and Thunderbird.
