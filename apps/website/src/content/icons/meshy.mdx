## About the Meshy logo

The Meshy logomark is a playful cartoon creature in pink, lime and green, with a thick dark outline and two small sparkles. The full logo sets the mark beside a condensed "Meshy.ai" wordmark. Both files come from the official Meshy media kit, which asks you not to modify them.

The media kit lists three brand colors: Meshy Lime (#C5F955), Meshy Pink (#FF3E8F) and Meshy Black (#181818). This full-color logo has a black wordmark meant for light backgrounds. It disappears on dark backgrounds, so use the mark alone or the monochrome version in dark themes.

## When to use this logo

Use the Meshy logo in AI 3D tool comparisons, text-to-3D and image-to-3D model tables, game asset and 3D printing pipeline diagrams, and docs for the Meshy API, MCP server or its Blender, Unity and Bambu Studio plugins. The media kit suggests the logomark for tight layouts and logo grids, and the full logo when space permits. It pairs naturally with Tripo, Luma, Blender, Unity and Unreal Engine.
