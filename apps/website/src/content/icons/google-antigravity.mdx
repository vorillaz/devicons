## About the Google Antigravity logo

The Antigravity icon is an arch, like a rounded "A" without a crossbar, with feet that flare outward. It is filled with soft, blurred patches of Google colours: blue (#3186FF), green (#00B95C), yellow (#FFE432) and red (#FC413D), in the same glowing gradient style as the Gemini mark. Google launched Antigravity in November 2025, alongside Gemini 3. The lockup sets "Google Antigravity" in dark grey (#202124) next to the arch.

The icon reads well on light and dark backgrounds. The grey wordmark disappears on dark surfaces, so use the monochrome lockup there.

## When to use this logo

Use Google Antigravity in AI coding tool comparisons, agentic IDE roundups and developer workflow diagrams. It pairs naturally with Google Gemini, Cursor, Windsurf, Claude Code and Visual Studio Code. Use the arch on its own for compact UI slots.
