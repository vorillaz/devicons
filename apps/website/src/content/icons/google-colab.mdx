## About the Google Colab logo

The Colab mark is a pair of interlocking rings that spell "CO", short for Colaboratory. Each ring is split into segments of Google yellow (#F9AB00) and orange (#E8710A). The full logo, used as the site logo on Google's Colab developer pages, writes "colab" in lowercase: the "co" is the ring mark and "lab" is set in the same yellow.

Both colors are bright enough to read on light and dark backgrounds, so the color version works on either. Use the monochrome version when the segment colors would clash with the layout.

## When to use this logo

Use Google Colab in data science and machine learning tutorials, "Open in Colab" style links in docs and READMEs, and notebook environment comparisons. It also fits course material and workshop slides that run code in the browser. Use the "CO" mark alone for badges, favicons and small buttons. It pairs naturally with Jupyter, Kaggle, Python, PyTorch, TensorFlow and Google Cloud.
