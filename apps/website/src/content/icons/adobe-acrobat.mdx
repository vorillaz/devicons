## About the Adobe Acrobat logo

The Acrobat icon is a dark red rounded square (#B30B00) with Adobe's white Acrobat symbol: a single looping stroke that forms a stylised triangle, often read as an "A". Unlike the two-letter Creative Cloud icons, Acrobat keeps its own symbol, the same ribbon that appears on PDF file icons.

The red tile reads well on light and dark backgrounds.

## When to use this logo

Use Adobe Acrobat for "open in Acrobat" buttons, PDF viewer and e-signature comparisons, document workflow diagrams and docs for the Acrobat Sign or PDF Services APIs. It pairs naturally with PDF, Microsoft Word, Adobe Photoshop, Google Drive and Dropbox.
