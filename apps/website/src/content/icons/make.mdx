## About the Make logo

The Make symbol is three rounded bars that lean in sequence, like falling dominoes; the source file names the shape "Logo Dominos". The full logo pairs the symbol with a heavy, lowercase "make" wordmark. Both files come from the official logo kit on Make's press page. Integromat became Make in February 2022, after Celonis acquired Integromat in 2020.

The bars use a radial gradient from pink-violet (#F024F6) to purple (#8200FA). The wordmark is black and disappears on dark backgrounds, so use the monochrome version, or the symbol on its own, in dark themes.

## When to use this logo

Use the Make logo in automation tool comparisons, integration and connector directories, "works with" sections, workflow and AI agent diagrams, and docs that explain how to connect an API or webhook to Make scenarios. It pairs naturally with Zapier, n8n, IFTTT, Pipedream and Microsoft Power Automate.
