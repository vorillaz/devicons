## About the Railway logo

The Railway symbol is a circle with the side view of a streamlined train nose cut into it. Horizontal speed lines run through it, and a single rail runs under it. The full logo pairs the symbol with a clean sans-serif "Railway" wordmark. Both files come from the vector logo in the header of railway.com, and the symbol matches the logo files Railway hosts under railway.com/brand.

The official logo is a single near-black color (#100F13), with an all-white version for dark backgrounds. Use the monochrome file in dark themes, because the dark logo almost disappears there.

## When to use this logo

Use the Railway logo in deployment target pickers, hosting and PaaS comparison tables, "Deploy on Railway" buttons and template galleries, architecture diagrams, and CI/CD docs. It pairs naturally with Vercel, Render, Fly.io, Heroku, Netlify and DigitalOcean, and with the databases it hosts, such as PostgreSQL, MySQL, Redis and MongoDB.
