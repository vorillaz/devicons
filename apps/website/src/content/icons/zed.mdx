## About the Zed logo

The Zed logo is a square outline in thick black lines with a stylised "Z" nested inside it. A diagonal stroke runs corner to corner, and the lines break and turn like a maze.

The black logo disappears on dark surfaces, so use the monochrome version in white there.

## When to use this logo

Use Zed in code editor comparisons, Rust tooling docs, AI coding tool roundups and developer setup guides. It pairs naturally with Visual Studio Code, Cursor, Neovim and Rust.
