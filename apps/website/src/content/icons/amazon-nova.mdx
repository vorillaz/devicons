## About the Amazon Nova logo

The Amazon Nova mark is an eight-point burst made of four zigzag arrows that point toward a common center. The full logo pairs the mark with an "Amazon Nova" wordmark. Both files come from the vector logo used on nova.amazon.com, and the mark matches the site's favicon. Amazon introduced the Nova models at AWS re:Invent in December 2024.

The mark uses a diagonal gradient from orange (#FF6200) through magenta (#E433FF) to violet (#6842FF). The wordmark is a dark navy (#161D26) that almost disappears on dark backgrounds, so use the monochrome version, or the mark on its own, in dark themes.

## When to use this logo

Use the Amazon Nova logo in model comparison tables, LLM provider and model pickers, benchmark charts, AWS architecture diagrams for generative AI workloads, and docs for SDK integrations that call Nova models through Amazon Bedrock. It pairs naturally with Amazon Bedrock, AWS, Claude, Llama and Mistral.
