## About the Microsoft Word logo

The Word icon is a stack of rounded panels in blue gradients, from light blue (#509DF5) to royal blue (#1657F4), with soft violet highlights. A smaller blue tile in front carries a white "W". It follows the layered Fluent style of Microsoft's current Microsoft 365 app icons, where Word, Excel, PowerPoint and Outlook share the same letter-tile layout in different colours.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft Word for .docx file-type icons, export and "open in Word" buttons, document workflow diagrams, office suite comparisons and docs for Office Add-ins or the Microsoft Graph API. It pairs naturally with Microsoft Excel, Microsoft PowerPoint, Microsoft Outlook, Google Docs and PDF.
