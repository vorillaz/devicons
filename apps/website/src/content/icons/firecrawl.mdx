## About the Firecrawl logo

The Firecrawl mark is an orange (#FA5D19) flame with an inner flicker cut out of its base. The lockup pairs the flame with the "Firecrawl" wordmark in near-black (#262626).

The orange flame reads well on light and dark backgrounds. The dark wordmark disappears on dark surfaces, so use the monochrome lockup there.

## When to use this logo

Use Firecrawl in AI data pipeline diagrams, RAG and agent tooling comparisons, web scraping API roundups and LangChain or LlamaIndex loader docs. It pairs naturally with Exa, Tavily, Jina AI, LangChain and Apify. Use the flame on its own for compact UI slots.
