## About the Ferris logo

Ferris is a smiling crab and the unofficial mascot of Rust; Rust users call themselves "Rustaceans", and the name is a nod to "ferrous", meaning containing iron. This icon is the "Happy" flat Ferris from rustacean.net, with an orange body (#F74C00), a darker rust-red (#A52B00) underside, and black eyes with white highlights.

Karen Rustad Tölva has dedicated Ferris to the public domain under CC0, so the artwork can be used, changed and shared freely. The orange reads well on both light and dark backgrounds. In the mono version the eyes and smile are cut out of the shell, so the face survives at small sizes.

## When to use this logo

Use Ferris for a friendly Rust touch: crate READMEs, conference slides, blog posts, Rust meetup pages, learning resources and "written in Rust" badges. Pair it with the official Rust logo when you need a formal language mark, and with Cargo or crates.io in Rust toolchain diagrams.
