## About the React logo

The React logo is the familiar atom-like mark: three overlapping ellipses orbiting a central nucleus. React grew out of an internal prototype by Facebook engineer Jordan Walke (early on called "FaxJS"). Facebook, now Meta, first used it in production on the News Feed in 2011 and open-sourced it at JSConf US in May 2013.

The cyan color (#61DAFB) has stayed consistent through every major release: the Fiber reconciler rewrite that shipped in React 16 (2017), Hooks in React 16.8 (2019), and the concurrent rendering features that arrived with React 18 (2022). When pairing the logo with a dark background it reads best at full saturation; on light surfaces, a slight outline keeps the thin ellipses visible.

## When to use this logo

Reach for the React logo in stack diagrams, hiring pages ("we build with…"), tutorial thumbnails, conference slides, and IDE plugin artwork. For commercial use on product pages, avoid implying endorsement from Meta or the React team, and check the trademark terms before printing the logo on packaging or merchandise.
