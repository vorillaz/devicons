## About the PDF logo

This is the PDF file icon: a white page (#F5F5F5) with a folded top-right corner and a red (#FF2116) outline. The red Adobe Acrobat ribbon sits in the middle, with the letters "PDF" in dark grey (#2C2C2C) below it. It matches the document icon Adobe Acrobat uses for PDF files.

The white page and red outline read well on light and dark backgrounds.

## When to use this logo

Use the PDF icon for file-type icons in upload widgets and file browsers, download and export buttons, document viewers and docs for PDF libraries such as PDF.js or pdf-lib. It pairs naturally with Adobe Acrobat, Microsoft Word, Google Docs and DocuSign.
