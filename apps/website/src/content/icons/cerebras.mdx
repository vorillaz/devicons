## About the Cerebras logo

The Cerebras mark is a set of orange (#F15A29) concentric arcs that open to the right like a stack of "C" shapes, wrapped around a black lowercase "c". The lockup continues that "c" into the black "cerebras" wordmark, so the arcs read as the first letter.

The black letters disappear on dark surfaces, so use the monochrome versions there.

## When to use this logo

Use Cerebras in LLM inference provider comparisons, AI hardware and accelerator overviews, model routing diagrams and docs for the Cerebras Inference API or OpenAI-compatible SDKs. It pairs naturally with Groq, NVIDIA, Together AI, Meta and Hugging Face.
