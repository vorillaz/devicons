## About the Microsoft Foundry logo

The Foundry icon is a folded ribbon that forms a stylized "A", with a small rounded square tucked into the fold. This file is the AI Foundry icon from Microsoft's official Azure architecture icon set, and it matches the favicon of the Foundry portal at ai.azure.com. Microsoft renamed the product from Azure AI Studio to Azure AI Foundry, and then to Microsoft Foundry. Microsoft does not publish a symbol-and-wordmark lockup for Foundry, so only the icon is included.

The ribbon uses a deep indigo-to-lavender gradient, from blue-violet (#302EC9) and dark indigo (#201BA6) to pale lavender (#CACAFB). The color icon reads well on both light and dark backgrounds. The monochrome version keeps the fold and the square as separate shapes.

## When to use this logo

Use the Foundry icon in cloud AI platform comparisons, LLM provider pickers that list Azure-hosted models, architecture diagrams for agent and RAG systems on Azure, and docs for SDK or MCP integrations that target Foundry projects. It pairs naturally with Microsoft Azure, Azure OpenAI, Amazon Bedrock and Google Vertex AI.
