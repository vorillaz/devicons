## About the GoDaddy logo

GoDaddy's symbol is the GO, a heart-shaped loop drawn with one continuous line whose inner curl forms a "G". GoDaddy introduced it in its 2020 rebrand, which retired the older logo with the "GoDaddy guy" character. The lockup pairs the GO with the "GoDaddy" wordmark, both in black here.

The black logo disappears on dark surfaces, so use the monochrome version in white there.

## When to use this logo

Use GoDaddy in domain and DNS setup guides, hosting provider comparisons, website builder roundups and docs for the GoDaddy Domains API. It pairs naturally with Cloudflare, Namecheap, Squarespace and WordPress.
