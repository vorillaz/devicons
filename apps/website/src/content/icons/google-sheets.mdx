## About the Google Sheets logo

The Google Sheets icon is a green page (#0F9D58) with a folded top-right corner in light green (#87CEAC) and a white grid of cells in the middle. It shares its folded-page shape with the Google Docs and Google Slides icons.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Google Sheets for spreadsheet import and export buttons, no-code and automation tool docs, Google Sheets API guides and data stack diagrams. It pairs naturally with Microsoft Excel, Airtable, Zapier and Looker Studio.
