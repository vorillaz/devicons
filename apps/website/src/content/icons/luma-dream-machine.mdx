## About the Dream Machine logo

The Dream Machine logo pairs Luma's folded-plane symbol with a two-line wordmark: "Dream" in a condensed serif above "MACHINE" in heavy sans-serif capitals. The symbol is two planes at 65% opacity that overlap into a darker fold. It comes from Luma's official media kit. The wordmark comes from the Lobe Icons set, because Luma no longer publishes a Dream Machine logo.

Luma launched Dream Machine in June 2024. Luma now lists it as a deprecated model that its Ray models have replaced. The logo is black, so use the monochrome version on dark backgrounds.

## When to use this logo

Use the Dream Machine logo in historical AI video model comparisons, research write-ups or benchmarks that cite Dream Machine results, and archived docs or tutorials written for it. For current Luma products, use the Luma logo. It pairs naturally with Runway Gen-3, Pika and OpenAI Sora, its 2024 peers.
