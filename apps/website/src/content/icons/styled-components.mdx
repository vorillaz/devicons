## About the styled-components logo

The styled-components logo is a thin grey (#4A4A4A) square frame holding a pair of angle brackets with a 💅 nail polish emoji between them, and "styled components" written in two lines below. The official logo draws the emoji with the system emoji font. This version uses the Noto Emoji vector (Apache License 2.0) so it renders the same everywhere.

The grey frame and text are hard to read on dark surfaces, so use the monochrome version there.

## When to use this logo

Use styled-components in React styling approach comparisons, CSS-in-JS migration guides, design system docs and component library stack diagrams. It pairs naturally with React, Chakra UI, Tailwind, Sass and Next.js.
