## About the Microsoft Excel logo

The Excel icon is a stack of rounded panels in green gradients, from light green (#4EB43B) to forest green (#073B10). A darker green tile in front carries a white "X". It uses the same layered Fluent layout as Microsoft's other Microsoft 365 app icons.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft Excel for .xlsx and CSV import or export buttons, spreadsheet file-type icons, BI and reporting tool comparisons and docs for Excel add-ins or the Microsoft Graph workbook API. It pairs naturally with Google Sheets, Power BI, Microsoft Word, Airtable and Python.
