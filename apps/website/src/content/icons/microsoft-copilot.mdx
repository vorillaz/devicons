## About the Microsoft Copilot logo

The Copilot logo is two interlocking, rounded ribbon shapes in a multicolour gradient. It runs from blue (#00AEFF) through green and yellow to orange (#FF5F3D) and pink. Bing Chat became Copilot in late 2023, and the colourful ribbon now marks Copilot in Windows, Edge, Microsoft 365 and the standalone app.

The gradient reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft Copilot in AI assistant comparisons, enterprise AI rollout plans, Windows and Microsoft 365 productivity guides and model picker designs. It pairs naturally with ChatGPT, Google Gemini, Claude, GitHub Copilot and Microsoft Office.
