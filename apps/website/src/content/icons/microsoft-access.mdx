## About the Microsoft Access logo

The Access icon is a cylinder, the classic database symbol, in red and pink gradients from deep red (#AA1D2D) to pink (#FF9FB2). A dark red tile in front carries a white "A". It uses the same layered Fluent layout as Microsoft's other Microsoft 365 app icons.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft Access in database tool comparisons, legacy app migration guides, .accdb file-type icons and ODBC connection docs. It pairs naturally with Microsoft Excel, Microsoft SQL Server, SQLite and Airtable.
