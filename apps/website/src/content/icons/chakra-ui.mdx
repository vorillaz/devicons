## About the Chakra UI logo

The Chakra UI icon is a rounded hexagon split into two halves by a zigzag lightning-bolt gap, each half filled with a teal gradient from deep teal (#3585A3) to mint (#00DEAE). The lockup adds "chakra" in a lowercase sans serif. This is the current logo from chakra-ui.com. It replaces the earlier teal circle with a lightning bolt.

The teal icon reads well on light and dark backgrounds. The black wordmark disappears on dark surfaces, so use the icon or the monochrome lockup there.

## When to use this logo

Use Chakra UI in React component library comparisons, design system docs, frontend stack diagrams and starter template READMEs. It pairs naturally with React, Next.js, shadcn/ui, Tailwind and Storybook.
