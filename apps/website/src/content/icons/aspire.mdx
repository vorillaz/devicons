## About the Aspire logo

The full-color icon uses the official
[original developer icon](https://github.com/microsoft/aspire-brand/blob/f9eb464dec47870de23d55dd7b3c00d39122813d/logo/developer-tools/aspire-original.svg).
Its monochrome counterpart uses the official
[plain developer icon](https://github.com/microsoft/aspire-brand/blob/f9eb464dec47870de23d55dd7b3c00d39122813d/logo/developer-tools/aspire-plain.svg)
from the Aspire brand repository. The `aspire-line` variant uses the official
[line developer icon](https://github.com/microsoft/aspire-brand/blob/f9eb464dec47870de23d55dd7b3c00d39122813d/logo/developer-tools/aspire-line.svg).
Both monochrome designs are filled paths, so they work directly in the icon font
without stroke conversion. All variants preserve the original proportions on the
Devicons 600-by-600 canvas.

## When to use this logo

Use the Aspire icon in distributed-application architecture diagrams, developer
tool listings, and documentation about local orchestration, observability, and
deployment. Aspire supports applications across multiple languages and frameworks.

[explicit developer-icon usage permission](https://github.com/microsoft/aspire-brand/tree/main/logo/developer-tools#developer-icon-usage-permission)
