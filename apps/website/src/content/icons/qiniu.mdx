## About the Qiniu Cloud logo

The Qiniu Cloud mark is a bull's head with two wide, upswept horns, a nod to the 牛 ("ox") in the company's Chinese name 七牛 ("seven oxen"). The full logo pairs the mark with the Chinese wordmark 七牛云. On qiniu.com the logo also carries the Hong Kong stock code 02567.HK under the wordmark, which these files leave out.

The mark and wordmark share one blue (#2468F2), taken from the logo SVG in the qiniu.com footer. It reads well on both light and dark backgrounds.

## When to use this logo

Use the Qiniu Cloud logo in storage and CDN provider comparisons, upload and media-processing integrations, video streaming architecture diagrams, and LLM gateway lists that include Qiniu's AI model APIs. It sits naturally next to Alibaba Cloud, Tencent Cloud, Volcano Engine and Baidu AI Cloud, and next to Cloudflare or AWS S3 in object storage overviews.
