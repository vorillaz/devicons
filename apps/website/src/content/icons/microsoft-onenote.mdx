## About the Microsoft OneNote logo

The OneNote icon is a stack of rounded panels in pink and purple gradients, from light pink (#FCB1FF) and orchid (#DE67FD) to deep purple (#580087). A smaller purple tile in front carries a white "N". It follows the layered Fluent style of Microsoft's current Microsoft 365 app icons, shared with Word, Excel, PowerPoint and Outlook.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft OneNote in note-taking app comparisons, Microsoft 365 suite diagrams, knowledge management stacks and docs for the OneNote API in Microsoft Graph. It pairs naturally with Microsoft Word, Microsoft Outlook, Microsoft Teams, Notion and Obsidian.
