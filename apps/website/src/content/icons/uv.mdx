## About the uv logo

The uv logo is a heavy, geometric lowercase "u" in bright magenta (#DE5FE9), cut by a narrow slot down the middle.

The magenta mark reads well on light and dark backgrounds.

## When to use this logo

Use uv in Python tooling comparisons, CI and Dockerfile docs, project READMEs that say "install with uv" and developer environment guides. It pairs naturally with Python, Ruff, Poetry, PyPI and Rust.
