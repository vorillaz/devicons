## About the TanStack logo

The TanStack icon is a near-black (#121212) rounded badge with a white palm tree standing on an island above white waves. The lockup puts a small version of the badge next to "TANSTACK" in heavy uppercase letters. TanStack Query, the library formerly known as React Query, has its own page with its own logo.

The near-black badge and wordmark disappear on dark surfaces, so use the monochrome versions there.

## When to use this logo

Use TanStack in React and Solid stack diagrams, data-fetching and routing library comparisons, full-stack framework overviews and docs for TanStack Start, Router or Table. It pairs naturally with React Query, React, Vite, TypeScript and Next.js.
