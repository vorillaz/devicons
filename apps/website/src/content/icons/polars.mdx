## About the Polars logo

The Polars logo is a polar bear drawn from vertical bars in shades of blue (#0075FF), like a bar chart shaped into the bear's body, head and legs.

The blue bars read well on light backgrounds and stay visible on dark ones.

## When to use this logo

Use Polars in DataFrame library comparisons, Python data stack diagrams, ETL pipeline docs and benchmark write-ups. It pairs naturally with pandas, NumPy, Apache Spark, Rust and Python.
