## About the Junie logo

The Junie mark is built from two green squares and a curved, J-shaped block arranged around an empty square. The full logo adds a black "Junie" wordmark with a smaller "by JetBrains" line under it. Both files come from JetBrains' official brand logo storage, and the mark matches the icon on junie.jetbrains.com.

The brand green is #48E054. The black wordmark disappears on dark backgrounds, so use the monochrome version, or the mark on its own, in dark themes.

## When to use this logo

Use the Junie logo in AI coding agent comparisons, JetBrains plugin and tooling docs, CI pipelines that run Junie from GitHub or GitLab, and terminal tool lists. It pairs naturally with JetBrains, IntelliJ IDEA and PyCharm, and with other coding agents such as Claude Code, Codex, Devin and Cursor.
