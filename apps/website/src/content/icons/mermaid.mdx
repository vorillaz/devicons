## About the Mermaid logo

The Mermaid icon is a white mermaid tail fin on a pink (#FF3670) rounded square. This is the version the project ships as the favicon of its documentation site.

The pink tile reads well on light and dark backgrounds.

## When to use this logo

Use Mermaid in diagram tool comparisons, docs-as-code guides, Markdown editor feature lists and READMEs that embed diagrams. It pairs naturally with PlantUML, Excalidraw, Markdown, GitHub and Docusaurus.
