## About the Ideogram logo

The Ideogram mark is a symmetrical, stylized brain built from rounded, lobe-like curves, with a subtle "I" in the negative space at its center. The full logo pairs it with a serif "Ideogram" wordmark. The identity was created by the agency How&How and covered by Creative Review in June 2026. The new mark flips the brain shape of Ideogram's earlier logo. Both files come from the logo SVG in the ideogram.ai site header.

Both the mark and the wordmark are a deep purple-black (#272038). They have very little contrast on dark backgrounds, so use the monochrome version in dark themes.

## When to use this logo

Use the Ideogram logo in text-to-image model comparisons, AI design tool directories, image generation API pickers, and docs for SDK or MCP integrations that call the Ideogram API. It works well wherever typography in generated images matters. It pairs naturally with Midjourney, FLUX, Stable Diffusion, Recraft and OpenAI's image models.
