## About the Adobe Illustrator logo

The Illustrator icon is a dark brown rounded square (#330000) with the letters "Ai" in orange (#FF9A00). It follows Adobe's app icon system, where each Creative Cloud app gets a two-letter mnemonic on a dark tile in its own colour.

The dark tile blends into very dark backgrounds, but the orange letters stay legible.

## When to use this logo

Use Adobe Illustrator in design tool comparisons, vector workflow guides, .ai and SVG export docs and icon production pipelines. It pairs naturally with Adobe Photoshop, Figma, Inkscape and Canva.
