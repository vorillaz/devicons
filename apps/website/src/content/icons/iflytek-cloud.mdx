## About the iFLYTEK Open Platform logo

The iFLYTEK Open Platform mark is a cloud shaped like a speech bubble, with a tail at the bottom left and five rounded vertical bars inside that suggest a voice waveform. The bars match the platform's focus on voice interaction. The full logo pairs the mark with the Chinese wordmark 讯飞开放平台, as shown in the header of xfyun.cn.

The mark is blue (#2A80E2) and the wordmark is dark grey (#333333). The wordmark fades on dark backgrounds, so in dark themes use the mark alone or the monochrome version.

## When to use this logo

Use the iFLYTEK Open Platform logo in speech recognition and text-to-speech provider comparisons, voice assistant architecture diagrams, LLM provider pickers that include iFLYTEK Spark models, and docs for SDKs that call xfyun.cn APIs. It pairs naturally with Baidu AI Cloud, Alibaba Cloud and Tencent Cloud speech services, and with Azure AI Speech and Google Cloud Speech-to-Text.
