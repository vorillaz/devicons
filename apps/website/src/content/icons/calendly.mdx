## About the Calendly logo

The Calendly icon is a soft, rounded tile in a blue gradient (#6AB0FF to #4793EB) with a white ring and a white "C" inside it. The lockup adds "Calendly" in near-black (#0B0D0F) next to the tile. Both are taken from the current logo on calendly.com.

The blue tile reads well on light and dark backgrounds. The dark wordmark disappears on dark surfaces, so use the icon or the monochrome lockup there.

## When to use this logo

Use Calendly in scheduling tool comparisons, sales and recruiting stack diagrams, booking embed docs and integrations with the Calendly API or webhooks. It pairs naturally with Cal.com, Google Calendar, Zoom, HubSpot and Salesforce.
