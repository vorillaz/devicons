## About the shadcn/ui logo

The shadcn/ui logo is two parallel diagonal strokes with rounded ends, one long and one short, in black. The slashes echo the slash in the project's name.

The black strokes disappear on dark surfaces, so use the monochrome version in white there.

## When to use this logo

Use shadcn/ui in React component library comparisons, design system docs, Next.js starter templates and UI stack diagrams. It pairs naturally with Tailwind CSS, Radix UI, Next.js, React and v0.
