## About the Zen Browser logo

The Zen Browser icon is three concentric rings in coral (#F76F53), thicker on the outside and thinner towards the centre, the same colour as the Zen website's favicon. The lockup pairs the rings with "zen browser" in lowercase, both in near-black (#202020).

The coral icon reads well on light and dark backgrounds. The near-black lockup disappears on dark surfaces, so use the icon or the monochrome lockup there.

## When to use this logo

Use Zen Browser in browser comparisons, privacy-focused setup guides, extension compatibility tables and dotfiles or desktop setup posts. It pairs naturally with Firefox, Arc, Brave, Chromium and Vivaldi.
