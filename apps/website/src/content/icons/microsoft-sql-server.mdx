## About the Microsoft SQL Server logo

The SQL Server icon is a folded ribbon shaped like an "S", in layered blue gradients from deep indigo (#312A9A) and Microsoft blue (#0078D4) to cyan (#3BD5FF), with soft lavender (#DECBFF) highlights. It arrived with SQL Server 2025 and follows Microsoft's Fluent product icon style. It replaces the red and grey tower logo that earlier releases used.

The icon reads well on light and dark backgrounds.

## When to use this logo

Use Microsoft SQL Server in database comparisons, .NET and Azure architecture diagrams, connection string docs and migration guides between relational databases. It pairs naturally with Microsoft Azure, .NET, PostgreSQL, MySQL and Microsoft Excel.
