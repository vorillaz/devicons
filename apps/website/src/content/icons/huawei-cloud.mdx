## About the Huawei Cloud logo

Huawei Cloud uses the Huawei corporate symbol, a fan of eight red petal shapes, as its mark. The full lockup places the stacked Huawei logo (the flower above "HUAWEI") to the left of a "HUAWEI CLOUD" wordmark in capitals. The flower artwork comes from the huaweicloud.com vector logo. The lockup follows the layout of the site header on the international website.

The petals use a radial gradient centered on Huawei red (#E60012), with a peach highlight at the top and darker red at the edges. Both wordmarks are black, so they disappear on dark backgrounds. Use the monochrome version in dark themes.

## When to use this logo

Use the Huawei Cloud logo in multi-cloud architecture diagrams, deployment target and region selectors, Terraform or SDK provider docs, and cloud pricing comparisons. It pairs naturally with Alibaba Cloud, Tencent Cloud, AWS, Google Cloud and Microsoft Azure.
