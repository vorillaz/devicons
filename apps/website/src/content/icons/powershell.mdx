## About the PowerShell logo

The PowerShell logo is a dark navy parallelogram, shaded from near-black (#0C131B) to slate blue (#2D4664), with a white prompt: a ">" chevron and an underscore. A light blue (#A9C8FF) highlight runs along its top edge.

The light edge and white prompt keep the logo legible on dark backgrounds.

## When to use this logo

Use PowerShell in shell and scripting language comparisons, Windows automation guides, .ps1 file-type icons and CI scripts. It pairs naturally with Bash, Windows Terminal, Azure, .NET and Microsoft PowerToys.
