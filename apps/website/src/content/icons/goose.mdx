## About the goose logo

The goose mark is a black silhouette of a goose in flight, seen from below with its wings spread and its neck stretched forward. The full logo pairs it with a lowercase "goose" wordmark, and the project writes its name in lowercase. The mark comes from the vector file in the goose GitHub repository, and it matches the logo on goose-docs.ai. In April 2026 Block donated goose to the Agentic AI Foundation (AAIF) at the Linux Foundation, and the repository moved from block/goose to aaif-goose/goose.

The logo is near-black (#101010). It disappears on dark backgrounds, so use the monochrome version in dark themes.

## When to use this logo

Use the goose logo in open-source AI agent comparisons, MCP server and extension directories, local-first developer tool lists, and docs that show how to connect goose to an LLM provider. It pairs naturally with the Model Context Protocol, Claude Code, Codex, OpenCode and Ollama.
