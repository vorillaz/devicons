## About the OpenCode logo

The OpenCode logo is drawn on a pixel grid, like a terminal font. The mark is a tall, square-cornered "O": a thick near-black #211E1E frame around a counter whose lower part is filled with light gray #CFCECD. The wordmark spells "opencode" in the same blocky lowercase letters, with "open" in mid gray #656363 and "code" in near-black.

The official brand page provides the logo and wordmark as separate files, each in light and dark versions. The light colors here have low contrast on dark backgrounds, so use the monochrome version there.

## When to use this logo

Use OpenCode in AI coding agent comparisons, terminal and CLI tool roundups, developer environment setup docs, and diagrams showing which models power a coding workflow. It also fits AI pair-programming tutorials and editor setup guides. It pairs naturally with Claude Code, Codex, Cursor, Aider and GitHub Copilot, and with model providers such as Anthropic, OpenAI and Google Gemini.
