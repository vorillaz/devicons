## About the Kagi logo

Kagi's brand guide names two assets. The main logotype is a lowercase "kagi" wordmark with a looping, tailed "g". The main symbol is that "g" alone in graphite on a yellow rounded square, used where the full logotype does not fit. Both files here come from the official Kagi Media Kit 2026. The name comes from the Japanese word 鍵 (kagi), meaning "key".

The main brand colors are yellow (#FFB319), graphite (#18181A) and white. The graphite wordmark disappears on dark backgrounds; the brand guide shows a white "negative" version for those, which the monochrome file covers.

## When to use this logo

Use the Kagi logo in search engine comparisons, privacy-focused tool lists, browser search-provider settings, and AI assistant or LLM provider pickers that include Kagi Assistant. It also fits developer docs that call the Kagi API, and "search with" menus in browsers and launchers. Natural pairings are DuckDuckGo, Brave Search, Perplexity and the Orion browser.
