## About the Home Assistant logo

The Home Assistant logo is a light blue (#18BCF2) house shape with a white, circuit-like tree inside it: a trunk that splits into three branches ending in circles. A light grey (#F2F4F9) fill behind the tree keeps it visible on dark backgrounds. The lockup adds "Home Assistant" in near-black (#1D2126).

The icon reads well on light and dark backgrounds. The dark wordmark disappears on dark surfaces, so use the monochrome lockup there.

## When to use this logo

Use Home Assistant in smart home dashboards, homelab diagrams, IoT integration docs and self-hosting guides. It pairs naturally with Raspberry Pi, MQTT, Node-RED, Docker and Google Home.
