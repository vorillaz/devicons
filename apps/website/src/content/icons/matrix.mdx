## About the Matrix logo

The Matrix logo is a black lowercase "m" between a pair of tall square brackets, written as [matrix] in text.

The black mark disappears on dark surfaces, so use the monochrome version there.

## When to use this logo

Use Matrix in chat platform and protocol comparisons, self-hosted communication stacks, bridge diagrams and docs for Matrix bots, the Client-Server API or homeservers. It pairs naturally with Element, Discord, Slack, Mastodon and Signal.
